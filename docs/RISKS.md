# 边界与注意事项

1. 开启“允许删除 NAS 文件”后，挂载路径上的删除会传到 NAS。Google 相册“释放空间”选择已备份内容；本应用不读取云端备份状态。NAS 回收站是否保留文件由服务器配置决定。
2. 默认只读；旧配置继续只读。可写挂载不等同于仅删除权限隔离。NAS 账号仍需相应权限，应用不改服务器权限。
3. 零媒体磁盘缓存仅指 rclone VFS；临时 SQLite、Google 相册缓存、MediaStore、缩略图和内核/内存缓冲仍有空间占用。
4. 扫描没有业务数量或总时长上限，仍受设备空间、内存、系统路径和网络约束。单次网络与媒体回调保留超时；阻塞的 FUSE 系统调用可能晚于网络超时返回。
5. 未加入后台扫描服务。切换 App 不主动取消，但锁屏、省电或系统终止进程可能中断任务。下一次手动扫描从头开始。
6. 清理只作用于已确认缺失的本地媒体索引，不直接删除 NAS 或 Google 云端文件。NAS 与 Android 扫描器无法形成跨系统原子事务；内容变化时应停止修改并重试。
7. 凭据通过 stdin 和环境传递，磁盘配置加密。已有 Root 的其他程序仍可能访问进程信息；不要输出环境变量或开启 shell tracing。
8. 限主用户 DCIM 独立子目录，拒绝外来、叠加挂载、非空目标和符号链接。不会修改 SELinux，不支持工作资料或任意系统路径。
9. APK 使用固定 debug 签名；可覆盖升级 0.1.2，仍属于可调试的侧载构建。
10. 挂载成功、索引成功、文件可读、Google 相册备份成功、相册释放空间成功需分别验证。
